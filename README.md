# DCOPMP320_data_structure_and_algorithm_assignment1_AHMADU_SUGARAY_KANU_ID_905006198
This assignment focuses on developing a Python program that can read, process, and evaluate mathematical expressions using a stack-based approach.
Program Flow
The overall program flow can be described as follows:
Step 1: Start
The program begins execution.
Step 2: Open Input File
The program opens:
input.txt
for reading.
Step 3: Read a Line
The program reads one line from the file.
Step 4: Check for Separator
The program checks whether the line is a separator.
If it is a separator, the program identifies the end of the current group.
If it is not a separator, the line is treated as a mathematical expression.
Step 5: Tokenize Expression
The expression is divided into individual tokens.
Step 6: Evaluate Expression
The tokens are processed using operand and operator stacks.
Step 7: Store Result
The calculated result is stored temporarily.
Step 8: Continue Reading
The program continues until all lines in input.txt have been processed.
Step 9: Write Results
The calculated results are written to:
output.txt
Step 10: End
The program closes the files and terminates
